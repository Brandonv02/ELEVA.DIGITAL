Fundamentos

Carbón frío como base, plata para la información secundaria y un único azul eléctrico reservado para lo que debe accionarse. Todo valor de aquí se traduce 1:1 a variables CSS y al theme de Tailwind.

Error de validación

Regla de uso del acento: como máximo un elemento azul sólido por pantalla visible. El resto del azul aparece como borde, texto o halo. Si todo es azul, nada destaca.

Contraste: #767E8D es el gris más claro admitido para texto (4.8:1 sobre carbón). Sobre la banda clara, el gris mínimo es #5A6373. Los rellenos sólidos usan #2558E6 y los enlaces sobre oscuro, #5B8CFF.
